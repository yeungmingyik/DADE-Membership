# DADE Membership

新加坡多门店会员服务平台 · Membership services for stores in Singapore

**版本 / Version:** 0.1.0

**阶段 / Stage:** 开发基线，业务功能尚未交付 / Development baseline; application features are not yet available

## 产品范围 / Product scope

以下为正式版目标功能。 / The following capabilities define the planned production scope.

| 使用端 / Surface | 功能 / Capabilities |
| --- | --- |
| 会员 / Members | 注册、数字会员卡、积分、等级、礼品与记录 / Registration, digital membership card, points, tiers, rewards and activity |
| 门店 / Stores | 会员识别、消费登记、礼品兑换、交付及授权退款 / Member identification, purchase recording, redemption, collection and authorised refunds |
| 总部 / Head office | 会员、门店、员工权限、礼品、规则、报表与审计 / Members, stores, staff permissions, rewards, rules, reporting and audit |

## 产品标准 / Product standards

- English 与简体中文 / English and Simplified Chinese.
- 注册默认新加坡 +65，支持国际手机号码 / Singapore +65 by default, with international mobile number support.
- 金额采用 SGD，业务时区为 Asia/Singapore / SGD amounts and Asia/Singapore business time.
- 会员、员工与总部独立入口 / Separate member, staff and head-office access.

## 技术方向 / Technology

Next.js · React · TypeScript · Tailwind CSS · shadcn/ui
